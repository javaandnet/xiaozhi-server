## 1. 使用的系统/方法

仓库采用 **npm** 作为包管理器，使用 ESM 模块语法（`"type": "module"`），通过 `package.json` 声明运行时依赖，并通过 `package-lock.json` 锁定精确版本。

- 包管理器：npm（由根目录的 `package.json` 与 `package-lock.json` 体现）
- 模块格式：ESM（`"type": "module"`）
- 引擎约束：`"engines": { "node": ">=18" }`
- 启动入口：`run-server.js`（脚本 `start` / `dev`）

## 2. 关键文件

- `package.json` — 唯一依赖清单，声明 9 个运行时依赖
- `package-lock.json` — npm 生成的锁文件，锁定所有依赖树的精确版本
- `.gitignore` — 忽略 `node_modules/`、`.env`、`config.json` 等生成/敏感文件
- `studio/lib/install.js`、`studio/lib/build.js` — Studio 子模块在安装/构建流程中可能触发额外安装（但依赖仍集中在根级 `package.json`）

## 3. 架构与约定

### 依赖范围
所有第三方库均声明在 `dependencies` 下，没有 `devDependencies`。依赖按功能分组：
- Web 框架：`express` ^4.22.1
- WebSocket：`ws` ^8.20.0
- 数据库：`better-sqlite3` ^12.6.2（SQLite 原生绑定）
- 语音处理：`opusscript` ^0.1.1（Opus 编解码）、`node-lame` ^2.0.2（LAME MP3 编码）、`node-edge-tts` ^1.2.10（Edge TTS）
- 前端 UI（服务端渲染/模板用）：`vue` ^3.5.43、`element-plus` ^2.14.6、`@element-plus/icons-vue` ^2.3.2
- 工具：`dotenv` ^16.6.1（环境变量加载）、`uuid` ^13.0.0（ID 生成）

### 版本策略
所有依赖使用 **语义化版本的 caret (^) 范围**，允许次版本/补丁更新，但不允许主版本升级。例如 `^4.22.1` 匹配 `>=4.22.1 <5.0.0`。

### 锁定机制
`package-lock.json` 已提交到仓库（不在 `.gitignore` 中），用于保证不同环境安装结果一致。`node_modules/` 被忽略，不纳入版本控制。

### 私有源/代理
未发现 `.npmrc`、`NPM_CONFIG_*` 环境变量或私有 registry 配置；依赖从 npm 官方源获取。

### 前端静态资源
`public/chat/js/live2d/` 下的 Live2D/Cubism 相关 JS 文件（`cubism4.min.js`、`live2dcubismcore.min.js`、`pixi.js`、`libopus.js`、`recorder.min.js`、`encoderWorker.min.js`）以源码形式直接放在仓库中，不走 npm 依赖，属于内联 vendored 资产。

## 4. 约定与约束

- **依赖声明位置**：所有 Node.js 依赖统一在根目录 `package.json` 的 `dependencies` 字段中声明，未在子目录发现独立的 `package.json`。
- **版本范围**：所有依赖使用 `^` 前缀的语义化版本范围，未出现无范围的硬编码版本。
- **Node 版本要求**：通过 `engines.node >= 18` 约束运行环境。
- **锁文件**：`package-lock.json` 随代码提交，`node_modules/` 被 `.gitignore` 排除，确保可复现的安装结果。
- **无开发依赖分离**：当前仓库未区分 `devDependencies`，所有依赖均为运行时依赖。
- **无私有注册表**：仓库中未发现 `.npmrc`、`registry=` 或 `NPM_TOKEN` 等私有源配置。
- **原生模块注意**：`better-sqlite3`、`node-lame` 为原生绑定依赖，安装时需要 C++ 编译工具链（由 npm install 自动处理）。
