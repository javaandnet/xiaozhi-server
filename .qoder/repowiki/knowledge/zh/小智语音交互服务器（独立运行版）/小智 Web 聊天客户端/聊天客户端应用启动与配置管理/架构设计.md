模块由三层组成：
- 页面壳 `public/chat/index.html`：通过 `<script type="module" src="js/app.js">` 引入主入口，并按顺序加载 UI/CSS、PIXI.js、Live2D SDK、Opus 解码器、录音库等全局脚本；同时内嵌 file:// 协议检测与全局 error/unhandledrejection 兜底。
- 应用启动层 `public/chat/js/app.js`：定义 `App` 类，在 `DOMContentLoaded` 中按序执行 UI 控制器、Opus 编码器/播放器、MCP 工具、麦克风权限、摄像头、Live2D 的初始化，并将实例挂载到 `window.chatApp` 供其他模块访问。
- 配置层 `public/chat/js/config/manager.js` + `default-mcp-tools.json`：提供 `loadConfig/saveConfig/getConfig/saveConnectionUrls` 等导出函数，以 `xz_tester_*` 为前缀读写 `localStorage`（MAC 地址缺失时自动生成）；默认 MCP 工具以 JSON Schema 形式声明 name/description/inputSchema/mockResponse，供 `core/mcp/tools.js` 消费。
依赖方向单向：app.js → config/manager.js 与 core/* 子模块，HTML 仅作为资源装配点，不承载业务逻辑。
