- 所有外部资源（WebSocket、AudioContext、Opus WASM）均以懒初始化 + 单例工厂（`getAudioRecorder` / `getAudioPlayer`）形式暴露，避免重复创建。
- 对浏览器环境差异的处理集中在入口处：iOS Safari 下检测 `AudioContext.state === 'suspended'` 并在用户交互事件上恢复上下文。
- PCM 数据在 Float32 与 Int16 之间转换时统一采用 ±1.0 ↔ ±32768 映射，并以 960 样本为单位进行分帧处理。
- 日志输出统一通过 `../../utils/logger.js` 的 `log(msg, level)` 调用，错误路径均记录 error/warning 级别日志。
- 阻塞型队列读写统一使用 `BlockingQueue` 的 `enqueue` / `dequeue`，配合 `while(true)` 异步循环驱动解码与播放流水线。
