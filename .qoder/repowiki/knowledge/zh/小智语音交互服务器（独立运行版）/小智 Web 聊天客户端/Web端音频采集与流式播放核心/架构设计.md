模块按 I/O 方向划分为四个文件：
- `opus-codec.js`：Emscripten 生成的 libopus 封装层，通过 `window.ModuleInstance`（或全局 `Module`）调用 `_opus_encoder_*` / `_opus_decoder_*` C 接口，负责 PCM↔Opus 转换及 WASM 内存分配/释放。
- `recorder.js`：录音侧，使用 `navigator.mediaDevices.getUserMedia` + `ScriptProcessorNode` 获取 Float32 输入，重采样到 16kHz、量化为 Int16，按 960 样本（60ms）切帧后经 `initOpusEncoder` 编码，由 `setInterval` 定时经 WebSocket 发送；同时提供测试模式（本地保存 PCM/Opus）、WAV 导出与下载。
- `player.js`：播放入口，持有单例 `AudioPlayer`，管理 `AudioContext`（16kHz, latencyHint=interactive）与 `BlockingQueue`，在 `start()` 中并行启动 `startAudioBuffering`（消费上游队列）和 `playBufferedAudio`（创建 `StreamingContext`）。
- `stream-context.js`：解码+调度核心，`decodeOpusFrames` 将 Opus 帧解码为 Float32 PCM 并推入 `activeQueue`，`startPlaying` 以 120ms 块通过 `createBufferSource` 精确调度到 `audioContext.destination`，并通过 `AnalyserNode` 暴露给 Live2D。
依赖方向单向：recorder → opus-codec；player → stream-context → opus-codec；三者共享 `utils/blocking-queue` 与 `utils/logger`。模块对外仅暴露 `getAudioRecorder` / `getAudioPlayer` / `checkMicrophoneAvailability` / `isHttpNonLocalhost` 等工厂函数，内部类不直接导出。
