以 `public/chat/js/app.js` 中的 `App` 类为唯一入口，在 `DOMContentLoaded` 后按固定顺序串联子模块：UI 控制器 → Opus 编解码 → 音频播放器 → MCP 工具 → 麦克风/摄像头权限检测 → Live2D 模型加载；各子模块之间不直接互相 import，而是通过 `window` 全局对象（如 `window.Live2DManager`、`window.chatApp`、`window.microphoneAvailable`）以及 DOM 元素进行松耦合通信。`index.html` 负责按依赖顺序引入 `live2d/live2d.js`、`app.js` 等脚本，形成“HTML 编排 + JS 模块”的双层装配。资源目录 `resources/hiyori_pro_zh` 与 `natori_pro_zh` 提供 Live2D 模型，`images/`、`css/` 提供静态素材，均由 UI 与 Live2D 子模块消费。
