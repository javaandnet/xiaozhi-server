- 具体服务类继承 `BaseService`，通过重写 `_initialize` / `_destroy` / `_healthCheck` 钩子实现初始化、清理与健康检查，公共入口 `initialize()` / `destroy()` / `healthCheck()` 由基类封装状态与异常。
- 可选能力通过构造函数 `enabled` 配置控制，并在 `isEnabled()` 中同时判断 enabled 与 initialized 状态，未启用时对外拒绝调用。
- 外部 HTTP/WebSocket 调用统一使用 `AbortSignal.timeout(timeoutMs)` 设置超时，避免长连接挂起。
- 第三方 SDK（opusscript、node-edge-tts、fs/path/os）采用动态 `import()` 延迟加载，降低冷启动依赖。
- 多提供商实现集中在一个类内部，通过 `switch (this.provider)` 分发到 `_init*` / `_recognizeWith*` / `_synthesizeWith*` 私有方法，新增提供商只需追加分支。
- 日志输出统一通过 `logger` 模块或带 `[${this.name}]` 前缀的 console 输出，便于区分不同服务实例。
