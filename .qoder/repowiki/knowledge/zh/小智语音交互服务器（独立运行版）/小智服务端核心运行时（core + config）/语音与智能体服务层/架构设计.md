模块以 `base.js` 中的 `BaseService` 抽象类为核心基类，所有具体服务（`LlmService`、`SttService`、`TtsService`、`VadService`、`VoiceprintService`、`McpService`）均继承它，统一暴露 `initialize()` / `_initialize()`、`destroy()` / `_destroy()`、`healthCheck()` / `_healthCheck()`、`isEnabled()`、`updateConfig()` 生命周期接口，由上层服务编排器按配置启用。

- 提供商多态：STT（`stt.js`）通过 `provider` 字段在 doubao/funasr/aibridge/xunfei/aliyun 间切换；TTS（`tts.js`）在 edge/xunfei/aliyun 间切换；LLM（`llm.js`）支持 openai（直连 aibridge OpenAI 兼容端点）与 dsh（DeepSeek Harness bridge），dsh 失败时回退 fallbackBaseUrl 或降级回复。
- MCP（`mcp.js`）独立于 BaseService 的扩展：定义 `ToolDefinition`/`ToolExecutor`/`ToolType`/`Action`/`ActionResponse` 执行框架，内置 `DeviceMCPExecutor`（调用设备端 MCP 工具）与 `MCPEndpointExecutor`（占位），并通过 `DeviceMCPClient` 维护每个连接的 jsonrpc 会话、工具列表与回调 Promise。
- 外部依赖方向：仅向上依赖 `utils/logger.js`，向下不反向被 services 内其他文件引用；网络 I/O 统一使用原生 `fetch` + `AbortSignal.timeout`，WebSocket 走 `ws` 库（STT）。`employeeBridge.js` 是纯函数模块，向 aiinterview 进程发起 `/api/xiaozhi/employee-turn` HTTP 请求。
- 音频管线：STT 负责 Opus→PCM 解码（`opusscript` 延迟加载）、VAD 集成、会话缓冲与流式发送；TTS 负责文本分段与 Edge TTS 合成；VAD 默认返回 null 交由调用方本地处理。
