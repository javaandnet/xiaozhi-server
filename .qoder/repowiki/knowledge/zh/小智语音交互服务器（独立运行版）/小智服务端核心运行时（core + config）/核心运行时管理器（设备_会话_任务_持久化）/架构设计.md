模块由四个并列的 Manager 类组成，每个文件对应一个领域：
- `device.js` → `DeviceManager`：以 `Map<clientId, DeviceModel>` + `Map<deviceId, clientId>` 双索引维护在线设备，提供增删改查、批量更新与离线清理。
- `session.js` → `SessionManager`：以 `sessionId→SessionModel` 主表 + `clientId→[sessionIds]` 反向索引管理会话，支持上下文存取、按客户端/全局过期清理与统计。
- `quest.js` → `QuestManager`：管理对话任务生命周期（active/paused/closed），维护 `clientActiveQuest` 活跃任务映射，并通过 `initializeQuestManager` / `getQuestManager` 暴露进程级单例。
- `store.js` → `XiaozhiStore`：基于 `better-sqlite3` 直接操作共享库 `data/xz.db`（表前缀 `xz_`），负责 `xz_devices` 与 `xz_conversations` 两张表的读写。
依赖方向单向向下：Manager 层仅依赖 `../models/*` 与 `../../utils/logger.js`；`store.js` 不依赖任何 Manager，是独立的持久化基础设施。所有写路径在 `store.js` 中通过 try/catch 捕获异常并降级为 no-op（`disabled` 标志），确保数据库不可用时语音主流程不受影响。
