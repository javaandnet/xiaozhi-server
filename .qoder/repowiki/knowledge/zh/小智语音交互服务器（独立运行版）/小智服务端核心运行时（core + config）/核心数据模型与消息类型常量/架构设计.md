模块由两个子目录组成：
- `core/models/`：基于 ES Module 的类层次结构。`base.js` 导出 `BaseModel`，提供统一的 `id`/`createdAt`/`updatedAt`/`deleted` 生命周期字段、`generateId`、`toJSON`、`update`、`delete` 以及供子类覆写的静态 `validate`；`device.js`、`session.js`、`quest.js` 分别继承 BaseModel，扩展各自领域字段（如 DeviceModel 的 `deviceId/clientId/capabilities/battery/signal/connection`、SessionModel 的 `context`、QuestModel 的 `tags/title/summary/messageCount`），并通过覆盖 `toJSON` 合并父类序列化结果。
- `core/constants/messageTypes.js`：纯常量模块，按客户端/服务端方向分组导出 `CLIENT_MESSAGE_TYPES`、`SERVER_MESSAGE_TYPES`，并聚合为 `MESSAGE_TYPES`，同时提供 `isValidMessageType`、`isClientMessageType`、`isServerMessageType`、`getMessageTypeName` 等校验与反向查找工具函数。
依赖方向单向：各 Model 仅依赖 `base.js`，常量模块无内部依赖；对外通过 ES `export default` / named export 暴露。
