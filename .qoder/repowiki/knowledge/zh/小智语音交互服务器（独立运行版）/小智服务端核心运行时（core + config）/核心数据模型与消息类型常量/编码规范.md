- 所有领域模型继承 BaseModel，在构造函数中调用 `super(data)` 并初始化自身字段，同时覆写 `toJSON` 以展开父类序列化结果。
- 每个模型提供静态 `validate(data)` 方法，返回 `{ valid, errors }` 结构，用于校验必填字段与枚举值范围。
- 状态变更方法（如 `updateActivity`、`close`、`pause`、`resume`）统一更新 `updatedAt = new Date()` 以保持审计时间戳。
- 消息类型以对象字面量分组导出（CLIENT/SERVER/TTS/LISTEN/CHAT/MCP/FRIEND），并通过 `MESSAGE_TYPES` 聚合及 `isValidMessageType` 等辅助函数提供统一访问入口。
