模块以 `routes.js` 作为 Express Router 入口（由外部 `run-server.js` 挂载到 `/firmware/api`），按职责拆分为四个 lib 子模块：
- `lib/util.js`：底层工具层，提供 `run`（bash -lc 子进程 + onLine 行回调）、`shq` shell 转义、`fetchJson`、全局 SSE 广播器 `SSE`。
- `config.js`：从项目级 `config.json` 的 `firmware` 段加载配置，并派生主服务 llm/stt 探活地址；路径支持 `XZ_CONFIG`/`XZ_DATA_BIN`/`XZ_DB_PATH` 环境变量覆盖。
- `lib/env.js`：环境探测与板型/设备识别，调用 `build.py --list-boards`、`sqlite3` 查询 `xz_devices`、macOS `ioreg` USB 描述符解析，结果带 60s 缓存。
- `lib/build.js`：异步构建任务管理器，维护内存 `Map<jobId, job>`，通过 `run` 执行三段式 shell 脚本（官方 build.py → perl 注入 OTA/wakeWord/flash8 → idf.py build），日志经 `SSE.send('build:log' | 'build:done')` 推送。
- `lib/install.js`：固件安装/删除/USB 烧录/源码同步，所有写操作返回 `{needConfirm}` 需前端二次确认，并对端口/路径做白名单校验。
依赖方向单向：routes → {env, build, install} → util；对外仅暴露 JSON + text/event-stream SSE，无模板渲染。
