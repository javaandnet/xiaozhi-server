入口 `run-server.js` 加载 `.env` 与 `config.json`，构造 `XiaozhiChannel`（server_core 导出）并调用其 `start()`；随后将 studio_cli 的 Express 路由挂载到同一 `channel.app` 上，使 WebSocket 通道、前端静态资源与固件工作台共享同一个 HTTP Server 与端口。
- server_core 通过 `index.js` 暴露 `XiaozhiChannel` 类与 `createPlugin` 工厂，内部组装 DeviceManager/SessionManager/Llm/Tts/Stt/Vad/Voiceprint/Mcp 等服务，并通过 `initializeWebSocketHandler` 注入这些服务实例。
- chat_client 作为 `public/` 下的静态页面被 `express.static` 提供，通过 `/api/websocket/urls` 获取 WS/WSS 地址后连接设备端。
- studio_cli 通过 `studio/routes.js` 暴露 `/firmware/api/*` REST/SSE 接口，由 `run-server.js` 在 channel 启动后挂载到同一 app。
- 三者之间不直接互相 import：server_core 与 studio_cli 通过共享的 `Express` 应用实例和 `config.json` 配置耦合；chat_client 仅依赖服务端暴露的 HTTP/WS API。
- 独立模式用 `SimpleBus` EventEmitter 空实现替代 gala 消息总线，LLM 走 bridge（provider=openai/dsh），不再依赖外部主智能体进程。
